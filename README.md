# WHO OWNS THE INTERNET?

An interactive frontend experience that explains what happens behind a web request and how the internet is assembled from networks, protocols and physical infrastructure.

## Features

- Cinematic responsive landing page
- Animated request trace
- Interactive DNS explorer (illustrative, no live lookup)
- HTTP vs HTTPS visualization
- Simplified global network map
- Undersea cable visualization
- CDN comparison
- "Who owns what?" infrastructure breakdown
- Interactive $100M internet-building simulator
- Responsive mobile navigation
- Scroll progress indicator
- No backend required

## Tech

- HTML5
- CSS3
- Vanilla JavaScript
- SVG/CSS visual techniques
- Google Fonts

## Run locally

Open `index.html` directly or use VS Code Live Server.

Recommended:
1. Open the folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select "Open with Live Server".

## Portfolio description

WHO OWNS THE INTERNET? is an interactive educational web experience that visualizes DNS, routing, HTTPS, CDNs, submarine cables and internet infrastructure through animations and small browser-based simulations.

## Important note

Network routes, IP values and infrastructure diagrams in this demo are simplified/illustrative. They are designed to teach concepts, not represent live routing or live infrastructure telemetry.
